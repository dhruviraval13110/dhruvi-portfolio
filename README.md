# Dhruvi Raval — Personal Portfolio

A modern, responsive personal portfolio for **Dhruvi Raval**, an AI/ML diploma student focused on learning by building.

## Stack

- Next.js
- React
- TypeScript
- Lucide React
- Custom responsive CSS

## Sections

- Hero / introduction
- About
- Technical toolkit
- Selected projects
- Learning journey
- Contact

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Before publishing

Update the placeholder email in `app/page.tsx`:

```text
dhruvi@example.com
```

Also replace the LinkedIn placeholder with Dhruvi's real profile URL.

## Deploy

This project is ready for Vercel or another Next.js-compatible host.
